# learning-about-version-control Jack Liu
Solving merge conflicts takes conscious effort, but I can do it!

One thing I like about version control is that multiple people can work on the same files in the repo at once thru branches, and all we need to know to get the updated file is just to use git push origin main

One thing I dislike about version control is dealing with merge conflicts. It is easy when people edit different files on different branches and merge them into main, but when two people edit the same file, it is very confusing/stressful to deal with merge conflicts.
